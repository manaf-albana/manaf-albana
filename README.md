- **التقنيات:** Python 3.10+, YOLOv8n-cls, OpenCV, ESP32, Servo & LEDs, ArduinoOTA, ThingSpeak TLS, SQLite (WAL), Chart.js
- **المزايا:** تصنيف لحظي لحالة المواقف عبر كاميرا الحافة بدقة تصل إلى **98.08%**، تحكم فوري في البوابة والمؤشرات عبر UART (`115200 baud`)، تخزين محلي بنمط `Store-and-Forward` عند انقطاع الشبكة مع إعادة مزامنة تلقائية، ولوحة تحكم حية مع كشف الشذوذ بقاعدة `2-Sigma`.

**منظومة هجينة لمعالجة وتدفق البيانات الضخمة وفحص الجودة الآلي (Hybrid Big Data ELT & Serving API)**
- **التقنيات:** Python, Apache Spark (PySpark), MongoDB, FastAPI, Uvicorn, APScheduler, PyTest
- **الآلية:** توجيه تلقائي للملفات حسب الحجم بين `Python Batch` و`Apache Spark`، تخزين الخام في `orders_raw`، وتطبيق 9 قواعد تطبيع حتمية للعملة والأرقام والتواريخ والهواتف العربية مع عزل السجلات التالفة (13 رمز تشخيص).
- **المزايا:** منع التكرار عبر تجزئة **SHA-256**، فهارس مركبة وفق قاعدة **ESR**، جداول مجمعة محدثة تزايدياً بالعلامة المائية، وواجهة **FastAPI** تضم 10 نقاط نهاية مع مهام مجدولة.
